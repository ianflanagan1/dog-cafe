# Suggest a feature, in Dog Cafe

## Pages

### Suggest a feature

`/suggest` · anyone

Suggest a new feature, or report a bug: a page with one text box and a Submit button, reached from Suggest in the header. Anyone can use it without logging in.

- Shows: “Suggest a new feature, or report a bug”
- Text box: “suggest”
- Button: “Submit”

## Things people do

### Sending a suggestion

`/suggest` · anyone

Pressing Submit on the Suggest a feature page sends what you wrote. It must be between 1 and 10,000 characters; if not, the page comes back with your text kept and a message saying what's wrong. Otherwise you see the Thank you! page.

- Can show: “`suggest` is required”
- Can show: “`suggest` can't be shorter than 1”
- Can show: “`suggest` can't be longer than 10000”
